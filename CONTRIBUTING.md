# Contributing

VectorAmp Labs is organized as a collection of independently reproducible labs.

Contributions should:

1. keep examples self-contained under `articles/<slug>/`;
2. include scalar correctness references for optimized kernels;
3. document the hardware and compiler used for published measurements;
4. commit raw benchmark data rather than only rendered charts;
5. avoid production credentials, customer data, and proprietary implementation details; and
6. pass the lab's documented build and test commands.

By submitting a contribution, you agree that it is licensed under Apache-2.0.
